# 🛍️ ShopEasy – E-commerce Website

ShopEasy is a responsive e-commerce web application developed using React.js and Node.js. It provides a simple and user-friendly shopping experience.

## 🚀 Features

- User Login
- Product Listing
- Product Details
- Add to Cart
- Wishlist
- Responsive User Interface
- Backend API Integration

## 💻 Technologies Used

**Frontend:**
- React.js
- HTML5
- CSS3
- JavaScript
- Axios

**Backend:**
- Node.js
- Express.js

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/codebyvarshini/ShopEasy-Ecommerce.git
```

### 2. Setup Backend

```bash
cd ShopEasy-Ecommerce/server
npm install
npm run dev
```

Backend runs at:

`http://localhost:5000`

### 3. Setup Frontend

Open another terminal:

```bash
cd ShopEasy-Ecommerce/client
npm install
npm run dev
```

Open the local URL displayed in the terminal.
